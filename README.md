📌 Visão Geral

O VidaSaúde Pro foi concebido com o objetivo de unificar a experiência de profissionais da saúde e pacientes em uma interface moderna e acessível. O sistema reúne recursos cruciais para a rotina médica e cuidados preventivos do paciente em um único ambiente web centralizado.

✨ Funcionalidades

🩺 Para Profissionais & Gestores

Painel Geral (Dashboard): Visualização consolidada de consultas do dia, métricas de atendimento e lembretes urgentes.

Prontuário Eletrônico: Registro e consulta de histórico médico, receitas, diagnósticos e exames anteriores.

Gestão de Agendamentos: Organização de horários, confirmações e cancelamentos de consultas em tempo real.

Relatórios & Analytics: Gráficos interativos para monitoramento do fluxo de pacientes e especialidades mais buscadas.

👤 Para Pacientes

Agendamento Online: Marcação rápida de consultas presenciais ou via telemedicina.

Lembrete de Medicamentos: Notificações e checklists para controle de horários de medicação.

Monitoramento de Bem-Estar: Acompanhamento de metas diárias (ingestão de água, passos, horas de sono e pressão arterial).

Acesso a Exames e Receitas: Download e visualização facilitada de documentos de saúde.

🛠️️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e bibliotecas:

HTML5: Estrutura semântica das páginas web.

Tailwind CSS: Framework utilitário de CSS para estilização ágil e responsiva.

JavaScript (ES6+): Lógica da aplicação, manipulação de estado local e interatividade.

FontAwesome / Lucide Icons: Ícones vetoriais modernos para a interface.

Chart.js: Renderização de gráficos e estatísticas visuais.

🚀 Como Executar o Projeto

Como o VidaSaúde Pro é uma aplicação web client-side (frontend), você não precisa instalar dependências pesadas de backend para testá-lo.

Pré-requisitos

Um navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

Extensão Live Server (recomendada para VS Code) ou similar.
